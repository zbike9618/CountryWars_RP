# CountryWars_RP

建国鯖のリソースパック。

## 本番への反映

- `main` に push すると、GitHub Actions が本番サーバーの「待ち」に置く（`.github/workflows/deploy.yml`）。
- 配っている RP が入れ替わるのは、次のサーバーの起動（4時・12時・18時の再起動など）の直前。それまでは全員に前のものが届き、起動の後は全員に新しいものが届く。
  - サーバーが動いている間に入れ替えると、前の版を持っている人には古いまま、初めて落とす人には新しいものが届き、人によって違って見えるため。
- 再起動までに何度 push しても、入るのは最後のものだけ。前と同じ中身に戻す push をすると、待ちは取り消される。
- **本番の RP のファイルを直接（Samba などで）直さない。** 直すときは main に push する。
- **manifest.json の版（`header.version`）は上げなくてよい。** 中身が変わっていれば、入れるときに自動で上げる（今まで使った一番大きい版の3つ目を +1）。手で上げた版が今までのどの版よりも大きければ、その版を使う。
- 中身が前と同じなら、何も入れ替えない（版も上げない）。
- そのため、リポジトリの manifest.json の版と本番の版は一致しない。入る版の見込みは Actions のログの「版 X.Y.Z を用意しました」で、実際に入った版は本番の `/home/minecraft/.deploy/countrywars-rp/deploy.log`（`applied` の行）で分かる。
- `README.md` と `.github` はパックに入れない。

仕組みの詳細は `.github/scripts/install_rp.sh` の先頭に書いてある。
